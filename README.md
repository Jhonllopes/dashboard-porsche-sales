# 🚀 Aceleração: AI Reports com Excel, GPT Agents e Claude Code

> Projeto desenvolvido durante a formação de **Aceleração em AI Reports**, com foco em automação de relatórios, análise de dados e geração de insights utilizando Inteligência Artificial.

---

## 🧠 Visão Geral

Este projeto demonstra como combinar ferramentas modernas de IA com análise de dados para criar **relatórios inteligentes automatizados**, utilizando:

- 📊 Excel como base de dados
- 🤖 GPT Agents para automação de análises
- 🧠 Claude Code para suporte na engenharia de dados e lógica
- 📈 Geração de insights e dashboards

O objetivo é simular um fluxo real de trabalho em **Data Analytics + IA aplicada a negócios**.

## 📊 Base de Dados

O projeto utiliza planilhas do Excel como fonte principal de dados para análise e geração de relatórios automatizados.

- 📁 Arquivo base: Planilhas do curso (Excel)
- 📌 Conteúdo:
  - Vendas
  - Faturamento
  - Indicadores de performance
  - Dados estruturados para análise
